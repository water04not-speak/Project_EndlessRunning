# EndlessRunning 跑酷小游戏

一个基于 C++ 和 EasyX 图形库开发的横版跑酷小游戏。项目实现了多层视差滚动背景、角色奔跑动画、跳跃/下蹲操作、随机障碍物生成、碰撞检测、生命值、得分、胜利/失败结算和音效播放，适合作为 C++ 图形编程、游戏循环和基础游戏开发实践项目展示。

> 项目定位：C++ 桌面端小游戏 / EasyX 图形编程 / 横版跑酷 Demo。

## 项目亮点

- 多层滚动背景：使用 3 层背景图按不同速度移动，形成横版跑酷常见的视差滚动效果。
- 角色动画系统：通过连续帧图片实现角色奔跑动画，并支持跳跃和下蹲动作切换。
- 随机障碍物：使用障碍物池管理多个障碍，包含小乌龟、狮子、柱状障碍等不同类型。
- 碰撞检测：封装矩形相交判断，根据角色当前状态动态计算碰撞盒。
- 游戏状态反馈：包含血条、得分、胜利界面、失败界面和碰撞音效。
- 音频播放：通过 Windows MCI 播放背景音乐、碰撞音效和胜利音效。
- 工具函数封装：将透明 PNG 绘制、音效预加载、碰撞检测、血条绘制等逻辑拆分到 `tools.cpp/h`。

## 游戏玩法

玩家控制角色在横向滚动场景中不断前进，通过跳跃和下蹲躲避障碍物。成功越过障碍会获得分数，碰撞障碍会扣除生命值。分数达到目标值后胜利，生命值归零后失败。

| 操作 | 按键 |
| --- | --- |
| 跳跃 | `Space` 空格键 |
| 下蹲 | `Z` |

游戏规则：

- 初始生命值：`100`
- 胜利条件：得分达到 `20`
- 碰撞惩罚：不同障碍物拥有不同伤害值
- 障碍生成：按随机间隔生成，提升躲避的不确定性

## 核心实现

### 游戏主循环

`main.cpp` 中通过 `while (1)` 构建游戏循环，并使用 `getDelay()` 控制刷新节奏。每隔约 30ms 更新一次画面：

1. 处理键盘输入。
2. 更新背景、角色和障碍物状态。
3. 批量绘制画面，减少闪烁。
4. 绘制角色、障碍、血条和分数。
5. 检查碰撞、胜利和失败状态。

### 视差滚动背景

项目加载 3 层背景图，并使用不同速度更新 X 坐标：

```cpp
int bgSpeed[3] = { 1, 3, 6 };
```

不同图层移动速度不同，使画面更有纵深感和速度感。

### 角色动作

角色拥有奔跑、跳跃和下蹲三种状态：

- 奔跑：循环播放 12 帧角色图片。
- 跳跃：通过 Y 坐标偏移模拟上升和下落。
- 下蹲：切换到下蹲图片，并调整碰撞区域。

### 障碍物系统

使用结构体描述障碍物：

```cpp
typedef struct obstacle {
    int type;
    int imgIndex;
    int x, y;
    int speed;
    int power;
    bool exist;
    bool hited;
    bool passed;
} obstacle_t;
```

项目通过固定大小的障碍物池复用对象，避免频繁创建和销毁，提高小游戏运行稳定性。

### 碰撞检测

`tools.cpp` 中封装 `rectIntersect()` 判断两个矩形是否相交。碰撞检测时会根据角色是否下蹲，动态计算角色碰撞盒，减少视觉和判定不一致的问题。

### PNG 透明贴图

EasyX 直接绘制 PNG 时可能出现透明区域异常。项目封装 `putimagePNG()` 和 `putimagePNG2()`，通过 Alpha 混合处理透明贴图，让角色和障碍物能自然叠加到背景上。

## 运行方式

### 环境要求

- Windows 10/11
- Visual Studio 2022
- EasyX 图形库

### 运行步骤

1. 安装 EasyX 图形库。
2. 克隆仓库：

```bash
git clone https://github.com/water04not-speak/Project_EndlessRunning.git
```

3. 使用 Visual Studio 打开 `Project_EndlessRunning.sln`。
4. 选择 `Debug | x64` 或 `Release | x64`。
5. 点击运行。

如果运行后资源无法加载，请确认 `res/` 目录与生成的可执行文件工作目录一致。

## 面试讲解重点

- 为什么要使用批量绘制：减少频繁刷新导致的画面闪烁。
- 如何实现视差滚动：不同背景层以不同速度移动。
- 如何设计障碍物系统：结构体 + 对象池 + 随机生成。
- 如何实现碰撞检测：根据角色状态计算碰撞盒，再做矩形相交判断。
- 如何处理透明贴图：手动进行 Alpha 混合绘制 PNG。
- 项目还能如何扩展：增加开始菜单、暂停、难度曲线、排行榜、道具系统和关卡配置。
